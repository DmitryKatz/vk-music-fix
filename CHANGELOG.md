# Изменения

## 1.2.0 — 2026-10-02

- **Главное исправление: зависший сервер больше не блокирует плеер.** Раньше, если один из серверов с музыкой (например `cs9-3v4`) переставал отвечать, его файлы занимали всю очередь фоновых загрузок. Плеер ВК ждал эту очередь и не мог начать даже трек с другого сервера. Сам плеер ВК в итоге падал с «Unknown error» и пропускал трек. Теперь:
  - если файл ещё не начал качаться, плеер не ждёт кеш и сразу берёт его из сети сам; если файл уже качается, ждёт не дольше 3 с;
  - каждая попытка скачать файл ограничена 15 с, всего попыток 3;
  - с одного сервера одновременно не больше двух фоновых загрузок;
  - сервер, который дважды не ответил, 2 минуты не используется для предзагрузки;
  - файлы трека, который нужен прямо сейчас, встают в начало очереди.
- **Честные подсказки.** Предупреждение «сеть сбоит» больше не срабатывает на запросы рекламы и статистики, которые режет блокировщик. Вместо него показываются конкретные тормозящие серверы с музыкой.
- «Empty src attribute» больше не считается ошибкой медиа: так ВК штатно создаёт пустые элементы.
- **В логе:** загруженные отрезки буфера, все перемотки (откуда и куда), детектор «играет, но стоит на месте».
- После `AbortError` трек не запускается, если уже играет другой элемент. Это защита от двойного звука.

## 1.1.0 — 2026-10-02

- **Возврат трека после сбоя плеера.** Когда HLS-модуль падает с «Unknown error» и плеер сам включает следующий трек, расширение возвращает упавший трек и перематывает на место обрыва. Не больше двух возвратов на трек и не больше шести в минуту.
- **Лог в файл.** Параллельная запись в выбранный файл. После перезагрузки страницы запись продолжается.
- **Скачать весь лог.** Полный лог из IndexedDB, включая прошлые сессии.
- **Глубокая диагностика:**
  - разбор `console.error` плеера с содержимым ошибок;
  - снимок состояния плеера в момент сбоя;
  - сетевые запросы плеера: статусы, таймауты, отмены;
  - ошибки MediaSource и SourceBuffer;
  - незагрузившиеся ресурсы сайта.
- В панели запросы плеера отделены от фоновых загрузок кеша.

## 1.0.0 — 2026-10-02

- Фикс `AbortError`: прерванный `play()` больше не скипает трек.
- Кеш трека целиком: заранее качаются все сегменты `.m3u8`, с повторами при обрывах.
- Панель отладки (`Alt+Shift+D`), отчёт в буфер обмена.
- `INSTALL.bat` для установки на Windows.
